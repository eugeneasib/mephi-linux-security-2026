# MEPHI Linux Security 2026

## Описание
Лабораторная работа по механизмам безопасности Linux.

Среда: Fedora Workstation 44, Oracle VirtualBox 7.2.20.

## Выполненные задания

### 1. Управление пользователями
Создан пользователь user1 с UID 1234 и группой students.
Установлена обязательная смена пароля каждые 90 дней.

### 2. Мониторинг безопасности
Найдены файлы с установленным битом set-UID.
Обнаружен процесс fusermount3 с RUID 1000 и EUID 0.

### 3. Механизм set-UID
Создана копия утилиты cat.
Установлен бит set-UID с владельцем root.
Проверено привилегированное чтение /etc/shadow.

### 4. Linux Capabilities
Создана копия утилиты chown.
Назначена привилегия CAP_CHOWN.
Проверено изменение владельца файла без sudo.

### 5. Механизм sudo
Пользователю user1 предоставлено ограниченное право
изменения системного времени с помощью date.

### 6. Сохранение результатов
Сохранены история команд, атрибуты файлов,
назначенные привилегии и результаты мониторинга.

### 7. Публикация
Результаты размещены в публичном репозитории GitHub.

## Файлы проекта

- mephi-screenshot.png — визуальное подтверждение.
- history.out — история команд Bash.
- stat.out — атрибуты каталогов и утилит.
- getcap.out — привилегии Linux Capabilities.
- suid-files.out — поиск файлов с set-UID.
- suid-permissions.out — права доступа к утилитам.
- processes.out — мониторинг процессов.
- passwd — учебная выборка учетных записей.
- shadow — обезличенная выборка из /etc/shadow.
- group — учебная выборка групп.
- sudoers — выборка системных правил sudo.
- sudoers-user1-time — правило sudo для user1.

## Безопасность

Системные файлы опубликованы в виде учебных выдержек.
